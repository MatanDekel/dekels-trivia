# טריוויה משפחתית 🎯 — dekels-trivia

אתר טריוויה בעברית: 6 נושאים מובנים + מיקס, 10 שאלות לסיבוב, 20 שניות לשאלה, בונוס מהירות ורצף.
כל שחקן מכניס שם (נשמר במכשיר), והתוצאות של כולם נשמרות בטבלת שיאים משותפת. אין הרשמה.

**מצב מנהלת** (בחלון השם → "כניסת מנהלת"):
- מחיקת תוצאות — בודדות או כל התוצאות של שחקן
- יצירה ועריכה של קטגוריות משלך; קטגוריה "🔒 רק אני" גלויה רק למנהלת (גם התוצאות בה)

## איך זה בנוי
- אתר Vite סטטי (`src/`) + פונקציות שרת של Vercel (`api/`)
- הנתונים נשמרים ב-**Vercel Blob** (store: `dekels-trivia-data`) — כל תוצאה היא קובץ נפרד
- הרשאות המנהלת נבדקות בשרת

## משתני סביבה ב-Vercel
| משתנה | תפקיד |
|---|---|
| `BLOB_READ_WRITE_TOKEN` | נוצר אוטומטית כשמחברים את ה-Blob store |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | פרטי הכניסה של המנהלת (להחלפת סיסמה: לשנות ולפרוס מחדש) |
| `ADMIN_SECRET` | מחרוזת אקראית לחתימת הכניסה (שינוי שלה מנתק את כל כניסות המנהלת) |

## פיתוח
```bash
npm install
npm run dev          # בלי /api האתר עובר למצב מקומי (נשמר בדפדפן)
vercel dev           # עם פונקציות השרת
npm run build:demo   # קובץ HTML יחיד לתצוגה מקדימה
```

## שאלות מובנות
ב-`src/questions.js` — `q` שאלה, `a` תשובה נכונה, `w` שלוש שגויות.
